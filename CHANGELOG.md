# Changelog

## 0.2.0
- Установка одной командой: `curl -fsSL …/install.sh | bash` (скачивает архив, ставит зависимости через apt, `--uninstall`).
- Ярлык в меню приложений: `.desktop` с абсолютным `Exec`, `StartupWMClass` и `Icon`, совпадающими с ID приложения; обновление кэшей.
- Исправлено: одна галочка отмечала несколько строк (состояние выбора теперь в модели, обработчики снимаются в unbind).
- Названия программ из `.desktop` (с локалью), имя пакета — второй строкой.
- Описания на русском: `Comment[ru]`, переводы APT (`Translation-ru`), локализованное описание Flatpak.
- Колонки «Установлено» и «Использовано» с сортировкой; иконки программ.
- Фоновый сбор метаданных с кэшем.

## 0.1.0
- Первый выпуск: список APT/Snap/Flatpak, поиск, фильтры, удаление с предпросмотром и защитой системных пакетов.
